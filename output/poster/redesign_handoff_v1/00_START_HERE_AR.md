# Forecast Select poster design experiment kit

Everything needed is included here, without discussion history or conflicting older versions. Approved text comes from the latest delivered poster. The design tool may change appearance and layout; content, figures, identity, and dimensions remain fixed.

1. Extract the package.
2. Copy all of `01_MASTER_PROMPT_EN.txt` into the tool being evaluated. It includes context, specifications, and the complete text; the other text files do not need to be pasted alongside it.
3. First attach `assets/Forecast_Select_CURRENT_Preview.png` and the original `brand/Khwarizme_Original_White_Logo.png`. If additional files are supported, attach the current PDF and PowerPoint and the original Khwarizme template. Poppins fonts are included under `brand/fonts/` if needed.
4. Ask the tool to follow the prompt and produce its best version. The same prompt provides a consistent challenge across tools; it does not depend on a specific Canva, Morph, ChatGPT, or Google image-tool feature.
5. Compare outputs with `ACCEPTANCE_CHECKLIST_EN.md`. An attractive image is insufficient if text, figures, or the logo change. An image-only output is a design concept; final print delivery must preserve legible text and actual dimensions.

## Files

- `01_MASTER_PROMPT_EN.txt`: the primary copy-ready file, containing all text and requirements in English.
- `POSTER_CONTENT_EN.txt`: poster text alone, for review or entry.
- `ACCEPTANCE_CHECKLIST_EN.md`: acceptance criteria and output comparisons.
- `REFERENCE_SOURCES_EN.md`: evaluation context and model references, for optional review rather than additional poster text.
- `assets/`: latest preview, PDF, and PowerPoint.
- `brand/`: original logo, official template, and Poppins fonts with their license.
- `MANIFEST_SHA256.json`: file hashes for package integrity checks.

Required dimensions: **841 × 1190 mm — Portrait**. Cohort text: **COHORT 3 AI TRACK**, without `/`. **≈62%** refers to the **Uptrend baseline: 61.81%**; the **Active selector: 60.97%** result must remain clear in the table.

The latest version is preserved. This package does not automatically publish the project or send it to a platform, and contains no training data or project secrets.
